# AI Agent 학습 문서 요청 안내

| 항목 | 내용 |
|---|---|
| 받는 분 | 제조팀 · 품질팀 · 영업팀 담당자 |
| 요청 | AI Agent 가 읽을 **현장 문서** 제공 |
| 기한 | ______ (담당자 협의) |
| 문의 | 시스템 담당 ______ |

---

## 왜 이 문서가 필요한가

시스템에 **AI Agent** 를 붙이는 중입니다. 작업자가 이렇게 물으면 답하는 기능입니다.

> "SUP_A 최근 입고 성분 편차가 어땠지?"
> "이 LOT 클레임 원인이 뭐야?"

**숫자로 답할 수 있는 질문은 이미 준비가 끝났습니다.** 입고 이력·성분 편차·품질 점수·
클레임 건수처럼 시스템에 저장된 것은 AI 가 바로 찾아 줍니다.

**문제는 숫자가 아닌 질문입니다.**

> "SAC305 배합할 때 온도를 몇 도로 맞춰야 하지?"
> "이런 클레임이 들어오면 어떻게 대응하지?"

이건 **사람 머릿속에 있거나 종이·엑셀에 흩어져 있는 지식**입니다.
시스템이 모르는 것이라 AI 도 답할 수 없습니다.

> **AI 는 아는 것만 답하도록 만들었습니다.** 모르면 "모른다"고 말합니다.
> 그럴듯하게 지어내지 않습니다. 그래서 **문서를 주시지 않으면 계속 "모른다"고만 답합니다.**

---

## 무엇을 주셔야 하나 — 5가지

우선순위 순입니다. **1번부터 하시면 됩니다.** 전부 한꺼번에 안 주셔도 됩니다.

| 순위 | 문서 | 담당 | 이 문서가 있으면 답할 수 있게 되는 질문 |
|---|---|---|---|
| **1** | **작업 표준서** | 제조팀 | "SAC305 용해 온도가 몇 도야?" · "배합 시간 기준이 뭐지?" |
| **2** | **검사 지침서** | 품질팀 | "출하 전에 뭘 확인해야 하지?" · "이 항목 판정 기준이 뭐야?" |
| **3** | **클레임 대응 매뉴얼** | 영업팀 | "젖음성 불량 클레임이 들어왔는데 어떻게 처리하지?" |
| **4** | **자재 기준서** | 제조팀 | "Sn 잉곳 입고 시 뭘 확인해야 하나?" |
| **5** | 배합 레시피 | 제조팀 | "이 제품 표준 배합이 뭐지?" |

## 1번은 지금 바로 하실 수 있습니다 — 화면에 직접 입력

**작업 표준서는 파일로 주실 필요가 없습니다.** 시스템에 입력 화면이 이미 있습니다.

### 들어가는 곳

```
왼쪽 메뉴 → 기준정보관리 → 작업 표준 → [+ 등록]
```

> 계정에 **제조 권한**이 있어야 등록 버튼이 보입니다. 안 보이면 시스템 담당자에게 문의하세요.

### 입력 항목 4개

| 항목 | 무엇을 넣나 | 예시 |
|---|---|---|
| **공정 코드** | 문서 번호. 규칙은 자유롭게 정하시되 **한 번 정하면 유지**해 주세요 | `MX-STD-001` |
| **제목** | 사람이 찾을 이름 | `SAC305 용해·배합 표준 작업지침` |
| **본문** | **실제 내용.** 여기가 핵심입니다 | 아래 참고 |
| **버전** | 개정 번호. 고칠 때마다 올라갑니다 | `1` |

### 본문은 이렇게 써 주세요

**이미 들어 있는 예시입니다. 이 정도면 충분합니다.**

```
1. 용해로 예열 후 표준 온도 235~255°C 를 유지한다.
2. 배합 시간은 40~50분으로 한다.
3. 성분 목표값은 Sn 62.0 / Ag 3.0 / Cu 0.5 (%) 다.
4. 품질 점수 70점 이상을 합격으로 한다.
```

**좋은 본문의 조건은 셋입니다.**

| | 이렇게 | 이러지 마세요 |
|---|---|---|
| **숫자를 넣는다** | "온도 235~255°C" | "적정 온도 유지" |
| **한 줄에 하나씩** | 번호를 매겨 나눈다 | 긴 문단 하나 |
| **판단 기준을 적는다** | "70점 이상 합격" | "품질이 양호할 것" |

> **표·그림은 넣지 마셔도 됩니다.** AI 는 글자만 읽습니다.
> 표에 있는 내용이라면 **글로 풀어서** 적어 주세요.
> 예: "온도 235~255, 시간 40~50분" 처럼요.

## 2~5번은 파일로 주시면 됩니다

### 형식

| 항목 | 내용 |
|---|---|
| **파일 형식** | 한글(.hwp) · 워드(.docx) · 엑셀(.xlsx) · PDF · 텍스트 — **아무거나 됩니다** |
| **전달 방법** | 시스템 담당자에게 전달 (담당: ______ ) |
| **분량** | 제한 없음. **있는 그대로** 주시면 됩니다 |

### 다듬지 마세요

**지금 쓰고 계신 문서를 그대로** 주시면 됩니다. AI 를 위해 새로 쓰실 필요 없습니다.
정리·번역·요약은 저희가 합니다.

다만 이런 것은 **미리 알려주시면** 도움이 됩니다.

- **이미 폐기된 문서** — 옛 기준이 답에 섞이면 위험합니다
- **아직 확정 안 된 초안** — 확정본만 넣겠습니다
- **사람 이름·연락처가 들어간 부분** — 빼고 넣겠습니다

## 자주 나오는 질문

**Q. 문서가 없으면 AI 를 못 쓰나요?**
아닙니다. **숫자로 답하는 질문은 문서 없이도 동작합니다.** 입고 이력, 성분 편차,
품질 점수, 출하 이력, 클레임 건수는 이미 시스템에 있습니다.
문서가 필요한 건 "기준이 뭐냐" 는 질문뿐입니다.

**Q. 문서를 넣으면 외부로 나가나요?**
질문에 답할 때 필요한 **일부 내용이 외부 AI 서비스로 전송**됩니다. 다만
**공급사명·고객사명·클레임 원문은 절대 나가지 않도록** 차단해 두었습니다.
LOT 번호 같은 식별자도 `LOT#1` 같은 임시 이름으로 바꿔서 보냅니다.
이 부분은 별도 보안 승인 절차를 밟고 있습니다.

**Q. 문서를 고치면 AI 도 바뀌나요?**
네. 작업 표준은 화면에서 고치시면 **버전이 올라가고 옛 버전은 보관**됩니다.
AI 는 항상 최신 버전으로 답합니다.

**Q. 얼마나 걸리나요?**
**작업 표준서 한 건이면 시작할 수 있습니다.** 전부 모아서 주실 필요 없습니다.
하나씩 넣으실 때마다 AI 가 답할 수 있는 범위가 늘어납니다.

**Q. 우리 공장 방식이 문서랑 다른데요?**
**실제로 하시는 방식을 적어 주세요.** 문서상 기준과 현장이 다르면,
AI 가 문서대로 답해서 현장과 어긋나게 됩니다. 실제가 정답입니다.

### 정리하면

1. **작업 표준서**는 `기준정보관리 › 작업 표준` 화면에 **지금 바로** 넣으실 수 있습니다
